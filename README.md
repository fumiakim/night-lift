# Night Lift

エレベーターアクション風の縦方向アクションゲーム。単一HTMLファイル、依存なし。ブラウザで `index.html` を開くだけで動作します。

**プレイする:** https://fumiakim.github.io/night-lift/

## 操作

| 操作 | キーボード | コントローラー |
| --- | --- | --- |
| 移動・乗降 | ← → | 左スティック / 十字キー左右 |
| ジャンプ | ↑ | **B**（L1 / L2 / 十字キー上）|
| しゃがみ | ↓ | 左スティック下 / 十字キー下 |
| 射撃 | Space | **A**（R1 / R2）|
| 決定 | Enter / Space | A / Start |

BluetoothコントローラーはOS側でペアリング後、ゲーム画面を一度クリックしてからボタンを押すと認識されます（Web Gamepad APIの仕様）。Safari・Chrome・Edgeで動作します。

A / B は Web Gamepad API の standard mapping（A = 下のボタン、B = 右のボタン）に従います。Nintendo系レイアウトのパッドは物理刻印と位置が入れ替わるため、刻印上は B が射撃・A がジャンプになります。

## ステージ

全8ステージ。1〜5面でひとつずつ仕掛けが増え、6〜8面はその組み合わせになります。

| 面 | 仕掛け | 背景 | 敵 | BGM |
| --- | --- | --- | --- | --- |
| 1 | 標準 | NIGHT（ビルの窓） | SENTINEL（APNG・灰色の人型） | NOIR |
| 2 | ＋照明が暗くなったり明るくなったりする | DUSK（ブラインド） | CREEP HEAD（ドット絵・頭部） | NOIR / DUSK |
| 3 | ＋エレベーターの速度が2倍 | DEEP SEA（気泡） | DIVER | NOIR / DEEP |
| 4 | ＋敵を倒すのに2発必要 | BIOHAZARD（斜線） | STALKER | NOIR / WIRE |
| 5 | ＋エレベーターが隣り合う | REACTOR（配管） | MAGMA | NOIR / BURN |
| 6 | 2 ＋ 3 | CRYO（氷紋） | GLACIER | NOIR / FROST |
| 7 | 4 ＋ 5 | VOID（回路） | WRAITH | NOIR / VOID |
| 8 | 2 ＋ 3 ＋ 4 ＋ 5 | FOUNDRY（鉄骨） | WARDEN | NOIR / FINAL |

- エレベーター・扉・脱出口の位置は全8面ですべて異なる。階数も5階から9階まで増えていく
- 敵のデザイン（シルエット・歩き方・配色）と背景のデザインは面ごとに固有
- 1面の敵は `dot_anim_3f 3.png`（APNG・60×60・3コマ×125ms）を無加工で使用。canvas は APNG を再生できないため、各コマを画素そのままで埋め込み、元ファイルと同じ間隔で切り替えている（3コマ目だけ目が赤く光る）
- 2面の敵は文字グリッドから描くドット絵スプライトで、宙に浮いて上下する
- 敵を倒したときの爆散パーティクルは、その面の敵と同じ色になる
- 2発必要な敵は頭上に装甲ゲージが出て、1発当てると装甲が裂ける
- 隣接エレベーターの面は、2基の間の足場が狭く乗り降りがシビアになる
- 8面をクリアするとエンディング（ALL CLEAR）。残機ボーナスを加えた最終スコアが表示される
- ゲームオーバー時は爆発演出
