# Night Lift

エレベーターアクション風の縦方向アクションゲーム。単一HTMLファイル、依存なし。ブラウザで `index.html` を開くだけで動作します。

**プレイする:** https://fumiakim.github.io/night-lift/

## 操作

| 操作 | キーボード | コントローラー |
| --- | --- | --- |
| 移動・乗降 | ← → | 左スティック / 十字キー左右 |
| ジャンプ | ↑ | **B**（L1 / L2 / 十字キー上）|
| しゃがみ | ↓ | 左スティック下 / 十字キー下 |
| 射撃 | Space | **A**（R1 / R2）|
| 決定 | Enter / Space | A / Start |

BluetoothコントローラーはOS側でペアリング後、ゲーム画面を一度クリックしてからボタンを押すと認識されます（Web Gamepad APIの仕様）。Safari・Chrome・Edgeで動作します。

A / B は Web Gamepad API の standard mapping（A = 下のボタン、B = 右のボタン）に従います。Nintendo系レイアウトのパッドは物理刻印と位置が入れ替わるため、刻印上は B が射撃・A がジャンプになります。

## 内容

- 全9ステージ。進むごとに階数・敵の数・速度が上がる
- ステージごとに背景（夜／夕暮れ／深海／バイオ／原子炉）とBGM（NOIRの5アレンジ）が変化
- 敵デザインは奇数面・偶数面で切り替わるドット絵アニメーション
- 3面・5面は照明が明滅し、暗い階では敵に見つかりにくい
- ゲームオーバー時に爆発演出
